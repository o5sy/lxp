AI 개발 멘토 — 배운 개념을 바로 실습으로

개발 학습자가 실습할 개념을 고르면, 개인화된 실습을 받아 AI 피드백까지 받는 학습 플랫폼입니다.

개념 선택→ AI가 실습 생성→ 웹 내 코드 편집기에서 실습→ AI 피드백
문제 / 배경

1차는 "일단 동작하는 것"에 집중했다

이상적인 시나리오로 일단 동작하는 것을 목표로 잡았습니다. 그 대가가 있었습니다.

  • 기능을 더 붙이면 기존 기능이 조용히 깨질 수 있다. 테스트 코드가 없으니 회귀를 잡아줄 안전망이 없었다
  • 어떤 응답이 올지 알 수 없었다. AI가 서비스의 핵심이라 응답 결과를 예측할 수 없었다
  • 새로고침하면 처음부터 다시. 진행 상태가 어디에도 안 남아 있었다

그래서 2차의 목표를 하나로 좁혔습니다 — 새 기능을 얹기 전에, 최소한의 품질부터 채운다.

3. LLM이 생성한 실습 품질 채점표 검증

같은 개념, 여러 번 생성해도 품질이 지켜지나

  • 왜: LLM 응답이라 프롬프트로 규칙을 지시해도 완벽히 통제되지 않는다 — 일관된 결과를 위해 응답을 채점하고 프롬프트를 개선한다
  • 어떻게: 생성 규칙을 코드 체크로 만들고, 실제 API 호출 결과를 저장해 그 샘플로 반복 채점한다 (업계는 LLM-as-judge를 쓰지만, 무료 토큰 제한·일정상 결정론적 로컬 스크립트를 택함)
